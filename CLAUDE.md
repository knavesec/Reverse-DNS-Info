# Claude Code Instructions

This file contains instructions for Claude Code when working on this project.

## Code Style Rules

### No Emojis
Do not use emojis in any file (Python code, documentation, comments, or output).
Use plain text alternatives instead:
- Instead of: ✓, ✅ → use: PASS, OK, SUCCESS
- Instead of: ❌, ✗ → use: FAIL, ERROR
- Instead of: ⚠️ → use: WARNING
- Instead of: ℹ️ → use: INFO, NOTE
- Instead of: 🔍 → use: SEARCH
- Instead of: 📝 → use: NOTE

## Project Context

This is a WHOIS and reverse-WHOIS reconnaissance toolkit for domain investigation.
Focus on reliability, live testing, and clear error reporting.
